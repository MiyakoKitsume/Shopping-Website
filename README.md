 # Field & Found

**Field & Found** is a static product showcase for objects with a point of view. The site presents a curated collection of distinctive, thoughtfully designed goods through an editorial-style visual experience.

## Overview

This project is a front-end school project focused on:

- Clear product discovery
- Strong visual hierarchy and art direction
- Responsive layout and typography
- A refined, editorial brand experience

## Features

- Branded landing page
- Featured product and collection sections
- Product imagery with descriptive content
- Responsive navigation and page layout
- Accessible semantic HTML structure
- Clean, minimal visual styling

## Getting Started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.

For a more reliable local preview, serve the folder with any static web server, for example:

```bash
python -m http.server
```

Then visit `http://localhost:8000`.

## Design Direction

The visual direction combines product-focused photography, generous spacing, expressive typography, and restrained interface elements. The goal is to make each object feel considered while keeping the browsing experience simple and intuitive.

## Accessibility

The project aims to support accessible browsing through:

- Semantic page structure
- Descriptive alternative text for meaningful images
- Visible focus states
- Sufficient color contrast
- Keyboard-friendly interactive elements

## Browser Support

The site is intended for current versions of Chrome, Edge, Firefox, and Safari on desktop and mobile devices.
